# Иллюстрация теплицы

`greenhouse-aerial.png` создана встроенным инструментом OpenAI image_gen по описанию для этого проекта. Это иллюстрация для режима «Фото», не фотография реального объекта и не камера наблюдения. Режим «3D» использует собственную геометрию Three.js.

Описание итогового запроса: фотореалистичная промышленная томатная теплица с приподнятого ракурса дрона в три четверти; несколько соединённых двускатных прозрачных стеклянных секций, серебристые металлические рамы, густые ряды томатов с красными плодами, розовая досветка, резервуары и трубы слева внизу; сельский промышленный ландшафт, дневной свет с прохладным голубым оттенком. Теплица занимает около 80% изображения. Без текста, элементов интерфейса, логотипов и водяных знаков.
